우선순위 시스템
High / Medium / Low 3단계 우선순위와 긴급도(Urgent / Not Urgent)를 조합해 아이젠하워 매트릭스로 시각화합니다. 우선순위별 XP 보상도 다르게 적용됩니다.
High = 30 XP Medium = 20 XP Low = 10 XP

마감일 & 캘린더 뷰
마감일 설정으로 캘린더 뷰에서 월간 일정을 한눈에 확인하고, 날짜에 드래그앤드롭으로 일정을 이동할 수 있습니다. 1일 전 / 당일 알림도 지원합니다.

실시간 검색 전체 필드 오버레이 UI

리스트 정렬 칸반 이동 캘린더 D&D

AI 개발 과정

Claude와 함께한
개발 여정

기획 단계부터 App Store 심사까지, Claude AI를 파트너 삼아 만들어온 과정입니다.

Step 01 — 기획
앱 구조 설계 & 기술 스택 선정
"어떤 TODO 앱을 만들고 싶은가"에서 출발해 Claude에게 시장 조사, 기술 스택 비교, 데이터 모델 설계를 요청했습니다. Next.js App Router + Firebase + Capacitor 조합을 추천받고, TypeScript 타입 설계까지 함께 진행했습니다.
📐 아키텍처 설계 🗄️ Firestore 스키마 📦 TypeScript 타입
Step 02 — 핵심 기능 구현
CRUD + 실시간 동기화 + 드래그앤드롭
할 일 CRUD, Firebase Firestore 실시간 동기화, @dnd-kit 기반 드래그앤드롭을 Claude가 코드를 작성하고 버그를 디버깅하는 방식으로 빠르게 구현했습니다. 오프라인 대응, 낙관적 업데이트, 충돌 해결 로직도 함께 설계했습니다.
🔄 실시간 sync ↕️ @dnd-kit 📴 오프라인 지원
Step 03 — 다양한 뷰 구현
7가지 뷰 모드 & 복잡한 UI 컴포넌트
캘린더, 칸반, 아이젠하워 매트릭스, GitHub 스타일 히트맵 등 복잡한 UI를 Claude와 반복적인 피드백 루프로 구현했습니다. Recharts 통계 차트, 포모도로 타이머 등 특수 컴포넌트도 프롬프트 몇 번으로 완성했습니다.
📅 캘린더 🗂️ 칸반 보드 📊 Recharts 🔥 히트맵
Step 04 — 게이미피케이션 & UX
XP 시스템, 업적, 온보딩 플로우
사용자 참여를 높이기 위한 게이미피케이션 시스템 설계를 Claude에게 요청했습니다. XP 밸런싱, 랭크 구조, 업적 조건, 온보딩 흐름 모두 AI와 협의해 결정했습니다.
🎮 XP 밸런싱 🏆 업적 시스템 👋 온보딩
Step 05 — iOS 네이티브 & 배포
Capacitor 빌드 & App Store 제출
Capacitor를 이용한 iOS 빌드 설정, WKWebView 특이사항 대응(Firebase inMemoryPersistence), 네이티브 알림 권한 처리, Vercel 배포 자동화 스크립트까지 Claude의 도움으로 완성했습니다.
📱 Capacitor iOS 🔔 로컬 알림 🚀 Vercel 배포
Step 06 — 테스트 & 품질
Vitest 기반 컴포넌트 & 훅 테스트
CLAUDE.md에 정의된 테스트 작성 원칙에 따라, 무의미한 어설션 없이 실제 기능을 검증하는 테스트를 작성했습니다. Red-Green-Refactor 사이클을 지키며 9개 테스트 파일을 완성했습니다.
🧪 Vitest ⚛️ Testing Library ✅ 9개 테스트 파일

데이터 모델링
Todo 타입 설계
TODO 앱의 TypeScript 타입을 설계해줘. 요구사항: - 우선순위: high/medium/low - 긴급도: urgent/not-urgent (아이젠하워 매트릭스용) - 마감일, 반복 설정 (daily/weekly/monthly) - 서브태스크 지원 - 포모도로 횟수 기록 - Firebase Firestore와 호환되는 구조 - soft delete 지원 (deletedAt 필드)
→ 결과: Todo, Subtask, Priority, Urgency 타입과 유틸리티 함수까지 포함한 완성도 높은 타입 시스템 생성
드래그앤드롭
@dnd-kit 칸반 구현
@dnd-kit으로 칸반 보드를 구현해줘. - 컬럼: Todo, InProgress, Done - 각 컬럼 간 드래그로 할 일 이동 - 같은 컬럼 내에서도 순서 변경 가능 - 이동 시 Firebase Firestore 즉시 업데이트 - 모바일 터치 지원 - 드래그 중 시각적 피드백 (opacity 변경)
→ 결과: DndContext, SortableContext, useSortable 훅을 활용한 완전한 칸반 보드 컴포넌트 구현
iOS 대응
WKWebView Firebase 오류 수정
Capacitor iOS 앱에서 Firebase Auth가 작동하지 않아. WKWebView 환경에서 IndexedDB가 제한되어서 발생하는 것 같아. 에러 메시지: "IDBFactory is undefined" next.js 앱에서 Capacitor를 감지해서 iOS일 때는 inMemoryPersistence를 사용하고 웹일 때는 browserLocalPersistence를 쓰도록 분기 처리해줘.
→ 결과: Capacitor.isNativePlatform() 감지 로직과 플랫폼별 Firebase persistence 분기 코드 완성
게이미피케이션
XP & 랭크 시스템 설계
TODO 앱에 게이미피케이션을 추가하고 싶어. - 할 일 완료 시 XP 획득 (우선순위별 차등) - 레벨 시스템 (레벨당 150 XP) - 5단계 랭크: 새싹 → 도전자 → 실천가 → 마스터 → 레전드 - 6가지 업적: 첫 완료, 10/50/100개, 고우선순위 마스터, 서브태스크 전문가 - useGamification 커스텀 훅으로 분리
→ 결과: XP 계산 로직, 레벨업 감지, 업적 조건 체크, 랭크 결정 함수를 포함한 useGamification 훅 완성
UI 컴포넌트
GitHub 스타일 히트맵
GitHub 잔디처럼 52주 활동 히트맵을 만들어줘. - 가로: 52주 (일요일~토요일) - 완료한 할 일 수에 따라 색상 강도 변화 - 다크모드 대응 (CSS 변수 활용) - 셀 hover 시 날짜와 완료 수 툴팁 - 반응형 (모바일에서 가로 스크롤) - Tailwind CSS 사용
→ 결과: 날짜 그리드 계산, 색상 인터폴레이션, 툴팁 로직까지 포함한 HabitView 컴포넌트 완성
테스트
useTodos 훅 테스트 작성
useTodos 커스텀 훅의 테스트를 작성해줘. 원칙: - expect(true).toBe(true) 같은 무의미한 어설션 절대 금지 - 실제 기능(추가/완료/삭제/필터)을 검증 - 경계값과 예외 케이스도 테스트 - Firebase는 mock 처리 - Vitest + Testing Library 사용
→ 결과: 실제 상태 변화를 검증하는 의미 있는 테스트 케이스 작성, 에지 케이스 포함
