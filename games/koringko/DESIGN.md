# 설계 — 태엽이 멈추기 전에

## 구조

| 위치 | 하는 일 |
|---|---|
| `src/core/adv/types.ts` | 무대 · 인물 · 대본 명령 · 방 · 장 모양 |
| `src/core/adv/stage.ts` | 무대 시간 흐름 (걷기 · 감정 말풍선 · 어두워지기 · 검은 띠 · 제목 카드) |
| `src/core/adv/script.ts` | 대본 실행기 (기다리는 명령에서 멈췄다가 다음으로) |
| `src/core/adv/parse.ts` | 대본 글 → 명령 (`who: 대사`, `> 해설`, `@walk …`, `@if … @end`) |
| `src/core/adv/adv.ts` | 한 판: 걷기 · 동료 따라 걷기 · 살펴보기 · 기억 조각 · 기억의 문 · 퍼즐 · 얼음 땡 · 저장 |
| `src/core/adv/mini.ts` | 작은 놀이 규칙 (종이별 · 촛불 · 바느질 · 인형극 · 태엽 · 기억 맞추기) |
| `src/core/adv/story/*` | 이야기: 장마다 방 지도 · 기억 · 대본 · 사람 크기 기억 방 · 가는 길 잡담 |
| `src/ui/adv/render.ts` | 방 · 인물 · 물건 · 밤 조명 · 빛살 · 비 |
| `src/ui/adv/overlay.ts` | 대화창(초상화) · 말풍선 · 고르기 · 제목 카드 · 기억 색감(세피아) · 놀이 화면 · 크레디트 |
| `src/ui/art/people.ts` · `house.ts` · `keepsakes.ts` | 사람(하루 4~15살 · 할머니 · 엄마 · 아빠 · 태엽 할머니 인형) · 기억 방 가구 · 상징물 |
| `src/ui/audio/score.ts` · `storysound.ts` | 「하루의 테마」 악보와 연주 (피아노 · 오르골 · 바탕 화음 · 심장) |

화면과 무관한 규칙은 모두 `core/` 에 있고 `node --test` 로 시험한다. 이야기 자료 테스트는 모든 대본이 끝까지 도는지, 모든 퍼즐이 풀리는지, 모든 기억 조각에 닿는지 확인한다.

## 투더문에서 가져온 것 · 고친 것

- 가져온 것: 거꾸로 거슬러 가는 기억, 되풀이되는 피아노 주제곡, 동료들의 티격태격, 상징물 복선(종이별 · 태엽 열쇠 · 편지), 기억의 문 맞추기 퍼즐, 게임 화면 안 연기(걷기 · 돌아보기 · 말풍선)
- 고친 것 (혹평): 놀 거리 부족 → 동료 능력 퍼즐 · 기억 속 조종 · 작은 놀이 · 얼음 땡 / 늘어짐 → 빠른 걸음, 꾹 눌러 대사 빨리 넘기기
