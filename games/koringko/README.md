# 코링코 탐험대

아이 방 한구석 장난감 나라의 **태엽 인형 탐험대 액션 RPG**.
태엽 할머니가 감아 깨운 토비가 집 안의 방을 하나씩 지나며 동료를 구하고, 먼지에 홀린 장난감들을 깨끗하게 해 블록 마을의 친구로 만든다.

- 의존성 없는 TypeScript + Canvas 2D, 그림과 소리는 모두 코드로 만든다 (그림·소리 파일 없음)
- PC (키보드 · 마우스) · 휴대폰 (가로 · 세로, 가상 조이스틱) 모두 지원
- 설계: [DESIGN.md](DESIGN.md)

## 이 게임만의 규칙 넷

1. **탐험대 교대** — 구한 동료끼리 E (또는 1~4) 로 바꿔 든다. 들어서는 순간 동료마다 다른 **교대 기술**이 터진다.
   쉬는 동료는 HP 가 천천히 차고, 싸우던 동료가 쓰러지면 다른 동료가 자동으로 나선다. 쓰러진 동료는 30초 쉬면 일어난다.
2. **태엽** — SP 대신 태엽(0~100). 스킬은 태엽을 쓴다. 저절로 조금씩, 적을 때리면, 그리고 **얼음 땡을 버티는 동안** 빠르게 감긴다.
3. **구해 주면 친구** — 쓰러뜨린 장난감은 깨끗해진다. 같은 장난감을 여러 번 깨끗하게 하면 구출되어 블록 마을 주민이 된다 (보스는 한 번에).
   친구 하나마다 탐험대 공격 · HP +1%, 친구가 늘면 마을이 커져 부품 칸과 가게 물건이 늘어난다. 도감에서 모아 본다.
4. **얼음 땡** — 방에서 가끔 아이의 발소리! 3초 뒤 '얼음' 동안 모두(몬스터도) 멈춘다. 움직이면 들켜서 HP 를 잃고 장난감들이 화가 난다.
   끝까지 참으면 HP 를 조금 되찾고 태엽이 감긴다. 처음 방에서는 아프지 않은 연습 얼음 땡부터 한다.

### 규칙 더 깊이
- **목표 화살표**: 지금 할 일이 있는 곳(주민 · 출구 · 고치 · 보스)을 노란 화살표가 가리킨다.
- **방마다 다른 얼음 땡**:
  - 장난감 상자: 발소리 (움직이면 들킴)
  - 과자 서랍: 엄마 손 (손 그림자 밖으로 피하기)
  - 침대 밑: 손전등 (지나가는 불빛 피하기)
  - 다락방: 먼지 왕 목소리 (짧은 경고, 긴 얼음)
- **블록 마을 시설** (마을 단계마다 하나):
  - 친구들의 집
  - 쉼터 방석: 돌아오면 모두 회복
  - 사탕 공장: 돌아올 때마다 사탕
  - 놀이터: 경험치 +10%
  - 축제 무대: 단추 +15%

## 보스 (장난감다운 규칙)

| 보스 | 규칙 |
|---|---|
| 태엽 곰 대장 | 기술마다 등의 태엽이 풀린다. 다 풀리면 4초 동안 멈춰 피해를 두 배로 받는다 |
| 젤리 여왕 | 체력 20% 마다 조각으로 쪼개진다. 조각이 기어 돌아가 닿으면 여왕이 회복한다 |
| 깡통 대장 | 자석으로 끌어당긴 뒤 둘레를 내려친다 (반대로 걷거나 굴러서 버티기), 태엽 쥐 부하 |
| 먼지 사도 더스티 | 불을 꺼 시야를 좁히고, 한 대면 터지는 먼지 분신을 부른다 |
| 먼지 왕 | 직접 "얼음!" 을 외친다. 움직이면 크게 다친다 |

## 퀘스트

| 종류 | 내용 |
|---|---|
| 주 이야기 | 동료 구출 · 보스 |
| 심부름 | 방에 떨어진 물건 찾아오기 |
| 친구 부탁 | 블록 마을 **부탁 게시판**. 구한 친구가 쪽지로 부탁한다 |

## 탐험대원

| | 직업 | 무기 | 교대 기술 | 만나는 곳 |
|---|---|---|---|---|
| 토비 | 토끼 검사 | 솜털 검 | 빙그르 베기 | 처음부터 |
| 보리 | 곰 도끼잡이 | 나무 도끼 | 땅 울리기 (기절) | 장난감 상자의 먼지 고치 |
| 루루 | 여우 궁수 | 고무줄 활 | 밀어내기 | 과자 서랍의 먼지 고치 |
| 나비 | 고양이 마법사 | 별 지팡이 | 서리 (느리게) | 책상 시계 공장의 먼지 고치 |

먼지 고치에 말을 걸면 먼지 무리가 세 번 몰려온다. 모두 물리치면 동료가 합류한다.
스킬은 A · S · D · F (궁극기) 와 지속 효과 하나, 공격 스킬마다 변형 셋. 레벨(탐험대 레벨)은 함께 오르고 스킬 점수는 동료마다 받는다.

## 성장 (장비 등급 · 전투력 숫자 없음)

- **무기 손질** (망치 너구리): 동료마다 무기 +0 ~ +19. 실패 없음. 단추 + 톱니 · 별가루 · 별 조각
- **부품** (재봉 토끼): 아홉 가지뿐. 만들고 꿰매 올리는 보통 부품 넷(핀 · 솜 · 천 · 스프링)과 보스가 처음 쓰러질 때 주는 특별한 부품 다섯. 탐험대가 함께 쓰는 부품 칸(3~6)에 끼운다.
- **단추**(돈) · **사탕**(Q, HP 회복) · 재료 다섯 가지

## 세계 (집 안의 방)

모든 방은 **한밤**이다. 주인공은 따뜻한 불빛을 들고 다니고, 야간등 · 창문 달빛 · 야광 별이 방을 비춘다.

| 방 | 레벨 | 동료 | 보스 |
|---|---|---|---|
| 블록 마을 (양탄자 위 벽돌 집 · 버섯 야간등) | 쉼터 | 쉬는 동료 · 구한 친구들이 돌아다닌다 | |
| 장난감 상자 (나무 상자 안 · 블록 더미 · 달빛) | 1~6 | 보리 | 태엽 곰 대장 |
| 과자 서랍 | 6~12 | 루루 | 젤리 여왕 |
| 책상 시계 공장 (책상 나무판 · 책 더미 · 공책 종이 · 스탠드) | 12~18 | 나비 | 깡통 대장 |
| 침대 밑 (어둠 · 먼지 덩이 · 야광 별) | 18~24 | | 먼지 사도 더스티 |
| 다락방 | 24~28 | | 먼지 왕 → 엔딩 |

엔딩 뒤 **다락방 상자 도전** (1~50층 한 판 로그라이트): 층마다 다른 방 모습 · 축복 카드 · 층 규칙 · 5층 체크포인트.
층 규칙에는 얼음 땡 잔치 · 교대 릴레이 · 보물 상자 같은 집 안 규칙도 있고, 10층마다 처음 정리하면 특별한 선물을 준다.
방마다 보물 상자가 숨어 있다. 난이도 쉬움 · 보통 · 어려움, 처음 안내, 휴대폰 자동 공격, 저장 칸 3개.
예전(장비가 있던) 판 저장은 이어할 수 없어 타이틀에서 알려 주고 지우고 새로 시작할 수 있다.

## 조작

| 키보드 | 하는 일 |
|---|---|
| 방향키 | 이동 |
| Z / 스페이스 / Enter | 공격 · 말 걸기 · 확인 (방향키와 함께 누르면 걸으면서 공격: 조금 느려지고, 가까운 적을 계속 조준) |
| X / Shift | 구르기 (잠깐 무적) · 창 닫기 |
| A S D F | 스킬 |
| Q | 사탕 |
| E · 1~4 | 동료 교대 |
| Esc | 메뉴 · C 탐험대 · K 스킬 · I 부품 · B 도감 · J 퀘스트 |

휴대폰: 왼쪽을 끌어 이동, 오른쪽 단추로 공격 · 구르기 · 스킬 · 사탕, 왼쪽 위 동료 얼굴을 눌러 교대. 아직 배우지 않은 스킬 단추는 보이지 않는다.

## 개발

```bash
npm install
npm test          # 코어 · 화면 로직 테스트 (node:test)
npm run typecheck
npm start         # 빌드 후 http://localhost:5180
npm run balance   # 봇이 동료 · 레벨 · 방별로 싸워 보는 균형 확인 (얼음 땡도 지킨다)
```

- `src/core/`: 화면과 무관한 게임 규칙 (지도 · 전투 · 탐험대 · 태엽 · 얼음 땡 · 친구 · 부품 · 구출 · 퀘스트 · 저장)
- `src/ui/art/`: 도트 그림 (인형 · 장난감 · 바닥 · 블록 · 아이콘)
- `src/ui/render/`: 지도 미리 그리기 · 장면 · 효과
- `src/ui/screens/`: 타이틀 · 대화 · 가게 · 무기 손질 · 부품 공방 · 다락방 상자 · 메뉴 · 이야기
- `src/ui/hud.ts` · `kit.ts` · `layout.ts`: HUD 와 창 도구 (키보드 · 마우스 · 터치가 같은 단추 목록을 쓴다)
- `src/ui/sound.ts` · `audio/`: 효과음 · 방별 배경음악 (Web Audio)

배포: `main` 에 올라오면 `.github/workflows/games-pages.yml` 이 탑 수호자와 함께 GitHub Pages 의 `/koringko/` 에 올린다.
