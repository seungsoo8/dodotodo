# 코링코 탐험대

장난감 나라 코링코를 지키는 네 인형의 **탑뷰 액션 RPG (핵앤슬래시)**.
마을에서 퀘스트를 받고, 사냥터에서 몬스터를 쓰러뜨려 장비를 모으고, 끝없는 다락방 균열에 도전한다.

- 의존성 없는 TypeScript + Canvas 2D, 그림과 소리는 모두 코드로 만든다 (그림·소리 파일 없음)
- 세밀한 도트 그림: 세계는 낮은 해상도로 그린 뒤 정수 배로 또렷하게 키우고, 글자는 화면 해상도로 그린다
- PC (키보드 · 마우스) · 휴대폰 (가로 · 세로, 가상 조이스틱) 모두 지원

## 탐험대원

| | 직업 | 무기 | 특징 |
|---|---|---|---|
| 토비 | 토끼 검사 | 검 | 빠른 세 번 베기 · 돌진 · 회전 베기 |
| 보리 | 곰 도끼잡이 | 도끼 | 묵직한 광역 · 포효 · 돌아오는 도끼 |
| 루루 | 여우 궁수 | 활 | 원거리 · 부채 화살 · 화살비 · 폭탄 |
| 나비 | 고양이 마법사 | 지팡이 | 화염구 · 얼음 장판 · 번개 사슬 · 운석 |

스킬은 A · S · D · F (궁극기) 네 개와 지속 효과 하나. 레벨 1 · 3 · 6 · 12 에 열린다.

## 조작

| 키보드 | 하는 일 |
|---|---|
| 방향키 | 이동 |
| Z / 스페이스 / Enter | 공격 (누르고 있으면 연속) · 말 걸기 · 확인 |
| X / Shift | 구르기 (잠깐 무적) · 창 닫기 |
| A S D F | 스킬 |
| Q W | 빨간 물약 (HP) · 파란 물약 (SP) |
| Esc | 메뉴 · C 상태 · I 장비 · K 스킬 · J 퀘스트 |

공격은 가장 가까운 적을 자동으로 겨눈다. 휴대폰에서는 왼쪽 화면을 끌어 이동하고, 오른쪽 단추로 공격 · 구르기 · 스킬 · 물약을 쓴다.

## 세계

- **코링코 마을**: 촌장 태엽 할머니, 잡화점 곰돌 아저씨, 대장간 망치 너구리, 재봉 토끼, 균열지기 별지기 부엉이
- **곰인형 숲** (Lv 1~6) → **과자 언덕** (Lv 6~12) · **태엽 동굴** (Lv 8~14, 보스 태엽 곰 대장)
- **다락방 균열** (1~50층): 몬스터를 쓰러뜨려 게이지를 채우면 수호자가 나온다. 5층마다 보스, 50층에 먼지 왕
- 장비 7부위 · 등급 5단계 (일반 · 매직 · 레어 · 유니크 · 전설, 전설은 고유 능력), 대장간 강화 +10 · 분해
- 퀘스트 · 이야기 장면 · 저장 칸 3개 (브라우저에 자동 저장)

## 개발

```bash
npm install
npm test          # 코어 · 화면 로직 테스트 (node:test)
npm run typecheck
npm start         # 빌드 후 http://localhost:5180
npm run balance   # 봇이 직업 · 레벨 · 지역별로 싸워 보는 균형 확인
```

- `src/core/`: 화면과 무관한 게임 규칙 (지도 · 전투 · 스킬 · AI · 보스 · 장비 · 퀘스트 · 저장)
- `src/ui/art/`: 도트 그림 (영웅 · 몬스터 · 땅 · 소품 · 아이콘)
- `src/ui/render/`: 지도 미리 그리기 · 장면 · 효과
- `src/ui/screens/`: 타이틀 · 대화 · 상점 · 대장간 · 균열 · 메뉴 · 이야기
- `src/ui/hud.ts` · `kit.ts` · `layout.ts`: HUD 와 창 도구 (키보드 · 마우스 · 터치가 같은 단추 목록을 쓴다)
- `src/ui/sound.ts` · `audio/`: 효과음 · 지역별 배경음악 (Web Audio)

배포: `main` 에 올라오면 `.github/workflows/games-pages.yml` 이 탑 수호자와 함께 GitHub Pages 의 `/koringko/` 에 올린다.
