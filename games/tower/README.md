# 탑 수호자

가운데 탑 하나를 지키는 자동전투 디펜스 게임 (간단 버전).
사방에서 몰려오는 적을 탑이 가진 무기로 자동 공격하고, 모은 골드로 상점에서 무기·강화를 사서 버틴다.
15라운드에 나오는 보스 「땅굴 군주」를 잡으면 승리, 탑 체력이 0이 되면 패배.

외부 런타임 의존성 없음 (TypeScript + Canvas 2D). Node 22.18 이상 필요.

## 실행

```bash
cd games/tower
npm install        # typescript, @types/node (개발용)
npm start          # 빌드 후 http://localhost:5173
```

## 조작

| 입력 | 동작 |
| --- | --- |
| 상점 칸 클릭 / `1`~`4` | 구매 |
| 리롤 버튼 / `R` | 상점 새로고침 (라운드 안에서 할 때마다 비용 +10) |
| `Space` / ⏸ | 일시정지 |
| `F` / ⏩ | 1배 ↔ 2배속 |
| `Enter` / 클릭 | 시작 · 재시작 |

## 규칙

- 라운드는 20초. 라운드마다 적이 더 많이, 더 강하게 나온다 (체력 ×1.16, 공격력 ×1.1, 현상금 ×1.08 / 라운드).
- 골드: 초당 기본 5 + 라운드마다 +1, 적 처치 현상금. 새 라운드가 되면 상점이 무료로 새로 채워진다.
- 무기 5계열
  - **일반**: 단일 대상 (돌팔매, 쌍단검)
  - **관통**: 가장 가까운 적 방향 직선 위를 모두 꿰뚫음 (장궁, 노포)
  - **마법**: 연쇄 번개(3회 튕김), 서리 구슬(2초간 50% 둔화)
  - **공성**: 착탄 지점 주변 광역 (박격포, 화염 항아리)
  - **카오스**: 피해가 매번 50%~200% (혼돈 구슬, 공허 광선)
- 강화: 튼튼한 벽(최대 체력), 재생의 룬, 강철판(방어), 전투 교본(피해 +10%), 황금 동전(초당 골드)
- 방어력: 받는 피해 = 공격력 / (1 + 방어력 × 0.05)

모든 수치는 `src/core/config.ts`(규칙)와 `src/core/data.ts`(무기·적)에서 조정한다.

## 구조

```
src/core/     게임 로직 (화면과 무관, 테스트 대상)
  game.ts     상태 · 진행(step) · 전투 · 상점
  config.ts   규칙 수치
  data.ts     무기 · 강화 · 적 정의
  rng.ts      시드 고정 난수 (같은 시드 = 같은 판)
src/ui/       화면
  layout.ts   상점 칸·버튼 배치, 클릭 판정, 화면 배율
  render.ts   캔버스 그리기
src/main.ts   게임 루프(고정 1/60초 스텝) · 입력
```
