# 탑 수호자

가운데 탑 하나를 지키는 자동전투 디펜스 게임.
사방에서 몰려오는 적을 탑이 가진 무기로 자동 공격하고, 모은 골드로 상점에서 무기·강화를 사서 버틴다.

판이 끝날 때마다 별조각이 쌓이고, 그걸로 탑을 영구히 강화하거나 새 탑·전설 무기를 연다.

- **클래식**: 15라운드에 나오는 보스(셋 중 하나)를 잡으면 승리, 탑 체력이 0이 되면 패배.
- **무한 모드**: 끝이 없다. 15라운드마다 더 강해진 보스가 나오고(체력 ×2.5, 공격력·현상금 ×1.5 씩), 보스를 잡아도 계속된다. 15라운드 이후에는 적 체력이 라운드마다 추가로 ×1.05 씩 강해지고 현상금은 더 오르지 않는다. 얼마나 오래 버티는지가 기록.

외부 런타임 의존성 없음 (TypeScript + Canvas 2D + Web Audio). Node 22.18 이상 필요.

## 실행

```bash
cd games/tower
npm install        # typescript, @types/node (개발용)
npm start          # 빌드 후 http://localhost:5173
```

5173 포트를 이미 다른 프로그램(예: 전에 켜 둔 게임 서버)이 쓰고 있으면 5174, 5175 … 로 알아서 넘어가고, 터미널에 실제 주소를 보여준다.
서버를 끌 때는 그 터미널에서 `Ctrl + C`.

## 조작

| 입력 | 동작 |
| --- | --- |
| 시작 화면에서 탑 카드 클릭 / `←` `→` | 탑 고르기 (잠긴 탑은 건너뜀) |
| 난이도 클릭 / `1` `2` `3` / `↑` `↓` + `Enter` | 난이도 선택 후 시작 |
| 시작 화면에서 탭 클릭 / `Tab` | 클래식 ↔ 무한 모드 |
| `S` / 강화 상점 버튼 | 영구 강화 (돌아가기는 `Esc`) |
| `A` / 업적 버튼 | 업적 목록 |
| 상점 칸 클릭 / `1`~`4` | 구매 |
| `Q` `W` `E` `D` / 아래 스킬 버튼 | 스킬 (메테오는 마우스 위치에, 버튼을 누르면 조준 후 클릭) |
| 왼쪽 무기 목록 두 번 클릭 | 무기 판매 (산 값의 50%) |
| 보상 카드 클릭 / `1` `2` `3` | 특전 고르기 |
| 리롤 버튼 / `R` | 상점 새로고침 (라운드 안에서 할 때마다 비용 +10) |
| `Space` / Ⅱ 정지 버튼 | 일시정지 (창을 떠나면 자동으로 멈춤) |
| `F` / ▶ 배속 버튼 | 1배 ↔ 2배속 |
| `M` / 오른쪽 위 ♪ 버튼 | 소리 켜기·끄기 |

## 규칙

- 라운드는 20초. 라운드마다 적이 더 많이, 더 강하게 나온다.
- 골드: 초당 기본 5 + 라운드마다 +1, 적 처치 현상금. 새 라운드가 되면 상점이 무료로 새로 채워진다.
- **난이도**: 쉬움(체력 1500 · 시작 골드 450 · 적 체력 ×1.13/라운드) / 보통(×1.17) / 어려움(×1.22, 적이 더 많음)
- **정예**: 5·10라운드 시작 때, 그때 나올 수 있는 가장 튼튼한 적이 체력 ×6 · 공격력 ×2 · 현상금 ×8 로 나온다.
- **무기 5계열 × 3종**

  | 계열 | 방식 | 무기 |
  | --- | --- | --- |
  | 일반 | 단일 대상 | 돌팔매, 쌍단검, 전투 도끼 |
  | 관통 | 가장 가까운 적 방향 직선 위를 모두 꿰뚫음 | 장궁, 질풍 활, 노포 |
  | 마법 | 연쇄 번개 / 둔화 | 연쇄 번개, 폭풍 수정, 서리 구슬 |
  | 공성 | 착탄 지점 주변 광역 | 박격포, 투석기, 화염 항아리 |
  | 카오스 | 피해가 매번 50~200% | 혼돈 구슬, 혼돈의 눈, 공허 광선 |

- **세트 보너스**: 같은 계열 무기 3개 → 그 계열 피해 +20%, 6개 → +50% 와 특수 효과
  - 일반: 공격 속도 +25% · 관통: 사거리 +40 · 마법: 연쇄 +2회, 둔화 +1초 · 공성: 폭발 반경 ×1.3 · 카오스: 피해 하한 100%
- **강화 9종**: 튼튼한 벽(최대 체력), 재생의 룬, 강철판(방어), 전투 교본(피해 +10%), 황금 동전(초당 골드), 신속의 룬(공격 속도 +25%, 최대 ×3), 예리한 칼날(치명타 10%, 2배), 가시 갑옷(탑을 때린 적에게 15), 망원경(사거리 +15)
- 방어력: 받는 피해 = 공격력 / (1 + 방어력 × 0.05)
- **무기 합성**: 같은 무기 ★1 3개 → ★2 (피해 ×3.5, 공격 속도 ×1.1), ★2 3개 → ★3 (피해 ×12, 공격 속도 ×1.25).
  탑에는 무기를 **10칸**까지 달 수 있고, 칸이 차면 사자마자 합쳐지는 무기만 살 수 있다. 세트 개수는 ★2 를 3개, ★3 을 9개로 센다.
- **판매**: 왼쪽 무기 목록을 누르고 한 번 더 누르면 판다. 산 값(★2 는 3배, ★3 은 9배)의 50% 환급.
- **스킬** (쿨다운이 있고 라운드에 따라 열림)

  | 키 | 스킬 | 열림 | 재사용 | 효과 |
  | --- | --- | --- | --- | --- |
  | Q | 메테오 | 1R | 30초 | 반경 55 광역 피해 (라운드가 오를수록 강해짐, 박쥐도 맞음) |
  | W | 눈보라 | 3R | 45초 | 모든 적 3초 동안 얼림 (움직이지도 공격하지도 못함) |
  | E | 긴급 수리 | 6R | 50초 | 탑 체력 35% 회복 |
  | D | 골드 러시 | 9R | 60초 | 10초 동안 처치 현상금 2배 |

- **보상 카드**: 3라운드마다 게임이 멈추고 특전 3장 중 1장을 고른다. 한 판에 같은 특전은 한 번만. 다 가지면 골드 주머니.
  연사 · 날 벼리기 · 이자 · 흡혈 탑 · 시체 폭발 · 다중 사격 · 전도체 · 거인 사냥꾼 · 행운 · 요새 · 현상금 사냥꾼 · 할인 · 무료 리롤 · 주문 숙련 · 냉기 오라 · 대폭발
- **적**

  | 적 | 등장 | 특징 |
  | --- | --- | --- |
  | 고블린 · 늑대 · 오크 · 돌 골렘 | 1 · 3 · 4 · 7R | 기본 적 |
  | 분열 슬라임 | 3R | 죽으면 새끼 슬라임 둘로 나뉨 |
  | 도둑 고블린 | 4R | 탑을 때리지 않고 골드를 훔쳐 달아남. 놓치면 골드를 잃고, 잡으면 되찾음 |
  | 방패병 | 5R | 일반·관통 무기 피해 절반 |
  | 주술사 | 6R | 멀찍이 멈춰 서서 2초마다 주변 적 치유 |
  | 박쥐 | 8R | 날아다녀서 공성(광역) 무기에 맞지 않음 |

  정예는 특수 능력이 없는 적 중에서만 나온다.
- **보스 3종**: 클래식 15라운드(무한은 15라운드마다)에 셋 중 하나가 나온다. 무한 모드에서는 바로 전 보스는 다시 나오지 않는다.

  | 보스 | 체력 | 패턴 (주기) |
  | --- | --- | --- |
  | 땅굴 군주 | 105,000 | 소환 (5초): 주변에 늑대·오크 6마리 |
  | 강철 뿔 | 90,000 | 돌진 (5초): 빠르게 달려와 공격력 ×3 으로 들이받음 |
  | 불꽃 마녀 | 80,000 | 멀리(115) 서서 불덩이를 쏘고, 화염 폭풍 (6초): 공격력 ×8 |

  - 패턴 전에 기를 모은다 (1~2초, 머리 위 `!` 와 경로·범위 표시). 이때 얼리거나(눈보라) 최대 체력의 4% 이상을 때리면 끊긴다.
  - 얼어 있는 동안에는 다음 패턴까지의 시간도 멈춘다.
  - 체력이 절반 아래로 내려가면 날뛴다: 이동 속도 ×1.3, 패턴 주기 ×0.6.
- **탑 5종** (시작 화면에서 고름)

  | 탑 | 시작 무기 | 고유 능력 | 해금 |
  | --- | --- | --- | --- |
  | 수호탑 | 돌팔매 | 최대 체력 +200, 라운드마다 체력 10% 회복 | 처음부터 |
  | 궁수탑 | 장궁 | 관통 피해 +30%, 관통 사거리 +30 | 별조각 30 |
  | 마법탑 | 연쇄 번개 | 마법 피해 +20%, 연쇄 +1, 스킬 대기 -25% | 40 |
  | 요새 | 박격포 | 체력 +300, 방어 +6, 가시 20, 공성 +20%, 무기 칸 8 | 50 |
  | 도박탑 | 혼돈 구슬 | 치명타 +10%, 카오스 피해 최대 300%, 리롤 반값 | 60 |

- **별조각** (판이 끝나면): 라운드 × 2 + 처치 수 / 40 + (클래식 승리 25 | 무한 보스 1마리당 15), 쉬움 ×0.7 · 어려움 ×1.5
- **영구 강화**: 시작 골드 +40 · 최대 체력 +80 · 피해 +4% (각 5단계), 초당 골드 +1 · 스킬 대기 -8% (각 3단계), 탑 4종 해금,
  전설 무기 3종 해금 (천둥 망치 · 불사조 활 · 유성 지팡이 — 해금하면 상점에 섞여 나온다)
- **업적 14개**: 첫 승리, 계열 하나로만 승리 (5계열 각각), 스킬 없이 승리, 어려움 승리, 체력 80% 이상 남기고 승리,
  ★3 무기, 무한 30라운드, 무한 한 판에 보스 3마리, 골드 2000 들고 끝내기, 다섯 탑 모두로 승리. 처음 달성할 때 별조각을 준다.
- **첫 판 안내**: 처음 하는 판에는 스킬 바 위에 그때그때 필요한 안내가 하나씩 뜬다 (무기 사기 → 합성 직전 → Q → W, 보스가 기를 모으면 끊는 법).
- 최고 기록 · 별조각 · 강화 · 업적 · 마지막으로 고른 탑은 브라우저(localStorage)에 저장된다. 클래식은 난이도별 최고 라운드 · 승리 수 · 최단 승리 시간, 무한 모드는 난이도별 최고 라운드 · 최다 처치.

## 연출

- 무기 15종(+ 전설 3종)마다 이름에 맞는 투사체와 착탄 효과 (`src/ui/weaponfx.ts`)

  | 무기 | 날아가는 모습 | 맞았을 때 |
  | --- | --- | --- |
  | 돌팔매 | 회전하며 살짝 포물선을 그리는 돌 | 돌 파편 |
  | 쌍단검 | 나란히 회전하는 단검 두 자루 | 베인 자국 |
  | 전투 도끼 | 크게 도는 도끼 | 두 번 베인 자국 + 파편 |
  | 장궁 | 붉은 깃 화살 | 불똥 |
  | 질풍 활 | 바람 줄기를 두른 초록 화살 | 바람 소용돌이 |
  | 노포 | 굵은 볼트 | 충격 고리 + 불똥 |
  | 연쇄 번개 | 지그재그 번개 | 전기 불꽃 |
  | 폭풍 수정 | 가지가 갈라지는 굵은 보라 번개 | 수정 조각 + 고리 |
  | 서리 구슬 | 눈가루를 흘리는 얼음 구슬 | 얼음 파편 폭발 |
  | 박격포 | 높은 포물선 포탄 (심지 불꽃) | 불덩이 폭발 |
  | 투석기 | 아주 높이 날아가는 바위 | 흙먼지 폭발 |
  | 화염 항아리 | 불붙은 항아리 | 폭발 + 한동안 남는 불꽃 |
  | 혼돈 구슬 | 좌우로 요동치는 보라 구슬 | 보라 흡수 폭발 |
  | 혼돈의 눈 | 가늘고 빠른 분홍 광선 | 분홍 불꽃 |
  | 공허 광선 | 검은 심과 보라 테두리의 굵은 광선 | 빨려 드는 공허 |

- 게임 로직은 쏘는 순간 피해를 주지만, 화면에서는 투사체가 닿는 순간에 맞은 것처럼 보이도록 피격·폭발·처치 연출을 착탄 시각까지 늦춘다. 투사체가 닿기 전에 죽은 적은 그때까지 화면에 남는다.
- 피해 숫자(치명타는 크고 붉게 튀어나옴), 맞은 적 흰색 깜빡임, 처치 시 연기와 HUD 로 날아가는 코인
- 화면 흔들림(폭발·피격·정예·보스), 보스 등장 경고 띠와 대사, 라운드·정예·세트 달성 배너
- 보스 패턴 예고: 돌진 경로, 탑을 조여 오는 불길, 소환 자리 표시, 기 모으기 막대와 끊기 막대, 끊으면 `끊었다!`
- 탑마다 깃발·구슬 색이 다르고, 결과 화면에서 한마디 한다
- 탑 체력이 35% 아래면 화면 가장자리가 붉게 맥박침, 패배 시 탑이 조각나 무너지고 승리 시 불꽃놀이
- 상점 카드: 마우스를 올리면 떠오름, 구매 시 번쩍임, 골드 부족 시 흔들림, 리롤 시 순서대로 뒤집힘

## 픽셀 글꼴 (선택)

기본은 시스템 한글 글꼴을 쓴다. 무료 픽셀 글꼴 [Galmuri](https://github.com/quiple/galmuri) (SIL OFL) 의 `Galmuri11.ttf` 를 `assets/` 에 넣고
`index.html` 의 `<style>` 에 아래 한 줄을 추가하면 모든 글자가 픽셀 글꼴로 바뀐다.

```css
@font-face { font-family: 'Galmuri11'; src: url('assets/Galmuri11.ttf') format('truetype'); }
```

모든 수치는 `src/core/config.ts`(규칙·난이도·세트), `src/core/data.ts`(무기·강화·적·보스 패턴), `src/core/heroes.ts`(탑), `src/core/meta.ts`(영구 강화)에서 조정한다.

```
  kit.ts      픽셀 스타일 창·버튼·막대·글자, 도트 그림 캐시
  effects.ts  투사체·번개·폭발·파편·숫자·코인·흔들림 효과
  fx.ts       효과용 계산 (이징, 흔들림, 번개 경로, 포물선, 숫자 줄임)
  weaponfx.ts 무기별 연출 사양과 착탄 시각 계산
  sprites.ts  적·탑·아이콘 도트 그림 (글자로 그린 픽셀 아트, 걷기 2프레임)
  sound.ts    Web Audio 로 즉석 합성하는 효과음 (throttle.ts 로 과다 재생 방지)
  records.ts  최고 기록 · 영구 진행 저장·불러오기 (깨진 값은 버림)
  tutorial.ts 첫 판 안내 (무엇을 보여줄지 고르기)
  summary.ts  결과 화면 무기별 피해 순위
  owned.ts    보유 무기 목록 묶기 · 누른 줄 찾기 (판매)
src/main.ts   게임 루프(고정 1/60초 스텝) · 입력
```
