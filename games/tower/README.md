# 탑 수호자

가운데 탑 하나로 네 방향을 막는 자동전투 디펜스 게임.

> 길잡이별이 떨어져 부서진 밤, 잿빛 안개에서 태어난 괴물이 네 갈래 길로 몰려온다.
> 마지막 마을 등불골의 교차로, 별조각을 품은 탑 하나만이 안개를 밀어낸다.

탑의 북·동·남·서 네 면에 무기를 나눠 달고, 라운드마다 어느 길로 적이 몰려올지 예보를 보고 대비한다.
무기는 알아서 쏘지만 **자기 면이 바라보는 쪽만** 쏜다. 무엇을 어느 면에 달지, 언제 옮길지가 이 게임의 핵심이다.

판이 끝날 때마다 별조각이 쌓이고, 그걸로 탑을 영구히 강화하거나 새 탑·전설 무기를 연다.

- **클래식**: 15라운드에 나오는 보스(셋 중 하나)를 잡으면 승리, 탑 체력이 0이 되면 패배.
- **무한 모드**: 끝이 없다. 15라운드마다 더 강해진 보스가 나오고(체력 ×2.5, 공격력·현상금 ×1.5 씩), 보스를 잡아도 계속된다. 15라운드 이후에는 적 체력이 라운드마다 추가로 ×1.05 씩 강해지고 현상금은 더 오르지 않는다. 얼마나 오래 버티는지가 기록.

외부 런타임 의존성 없음 (TypeScript + Canvas 2D + Web Audio). Node 22.18 이상 필요.

## 실행

```bash
cd games/tower
npm install        # typescript, @types/node (개발용)
npm start          # 빌드 후 http://localhost:5173
```

5173 포트를 이미 다른 프로그램(예: 전에 켜 둔 게임 서버)이 쓰고 있으면 5174, 5175 … 로 알아서 넘어가고, 터미널에 실제 주소를 보여준다.
서버를 끌 때는 그 터미널에서 `Ctrl + C`.

## 조작

| 입력 | 동작 |
| --- | --- |
| 시작 화면에서 탑 카드 클릭 / `←` `→` | 탑 고르기 (잠긴 탑은 건너뜀) |
| 시작 화면 `T` / 이야기 버튼 | 이야기 책 (↑↓ 쪽 넘기기) |
| 이야기 카드에서 클릭 · `Enter` / `Esc` | 다음 / 건너뛰기 |
| 난이도 클릭 / `1` `2` `3` / `↑` `↓` + `Enter` | 난이도 선택 후 시작 |
| 시작 화면에서 탭 클릭 / `Tab` | 클래식 ↔ 무한 모드 |
| `S` / 강화 상점 버튼 | 영구 강화 (돌아가기는 `Esc`) |
| `A` / 업적 버튼 | 업적 목록 |
| `L` / 연습 판 버튼 | 연습 판 (따라 하며 배우기, 언제든 다시 할 수 있다) |
| 아래 상점 카드 클릭 / `1`~`4` | 구매: 산 무기는 **지금 고른 면**에 붙는다 (카드에 마우스를 올리면 자세한 설명) |
| `↑` `→` `↓` `←` / 탑 옆 빈 칸 클릭 | 면 고르기 (북·동·남·서) |
| `Z` `X` / 스킬 바 양옆 둥근 화살표 | **탑 돌리기** (반시계 · 시계 방향으로 90°, 8초마다) |
| 탑 옆 무기 칸 클릭 → 다른 면 칸 클릭 (또는 방향키) | 무기 옮기기 (옮긴 무기는 3초 동안 쏘지 않음) |
| 탑 옆 무기 칸 클릭 → 옆에 뜨는 `팔기` | 무기 판매 (산 값의 50%) |
| `Q` `W` `E` `D` / 아래 스킬 버튼 | 칸의 스킬 (운석 스킬은 마우스 위치에, 길 스킬은 마우스가 있는 길에. 버튼을 누르면 조준 후 클릭) |
| 보상 카드 클릭 / `1` `2` `3` | 특전 또는 스킬 고르기 |
| `Esc` / 우클릭 | 조준·집은 무기 취소 |
| 상점 오른쪽 ⟳ 버튼 / `R` | 상점 새로고침 (라운드 안에서 할 때마다 비용 +10) |
| `Space` / 오른쪽 위 Ⅱ 버튼 | 일시정지 (창을 떠나면 자동으로 멈춤) |
| `F` / 오른쪽 위 › 버튼 | 1배 ↔ 2배속 |
| `M` | 소리 모두 끄기·켜기 |
| 오른쪽 위 ♪ 버튼 | 소리 창 (효과음·음악 음량 막대, 모두 끄기) |
| 오른쪽 위 i 버튼에 마우스 (터치는 한 번 눌러 켜고 끄기) | 고른 탑 · 능력치 · 특전 · 다음 보스 |

- 한글 자판 상태여도 같은 자리의 키로 읽는다 (`ㅂ` = `Q`). `Ctrl`·`Cmd` 조합과 누르고 있는 키의 반복 입력은 무시한다.
- 보상 카드는 뜬 뒤 0.4초, 결과 화면은 1.2초 동안 입력을 받지 않는다 (연타하다 잘못 고르지 않게).
- 터치: 작은 버튼은 가장자리 바깥 조금까지 눌린다.
- 휴대폰을 세로로 들면 자동으로 멈추고 가로로 돌리라고 알려 준다.

## 규칙

- 라운드는 20초. 라운드마다 적이 더 많이, 더 강하게 나온다.
- 골드: 초당 기본 8 + 라운드마다 +2, 적 처치 현상금. 새 라운드가 되면 상점이 무료로 새로 채워진다.
- **네 면**: 탑에는 북·동·남·서 네 면이 있고 면마다 무기 칸이 3개(요새는 2개)다.
  - 무기는 자기 면 정면에서 좌우 60°(모두 120°) 안의 적만 쏜다. 대각선은 이웃한 두 면이 같이 맡는다.
  - 화면이 가로로 길어서 **동·서 길은 길고(320) 북·남 길은 짧다(180)**. 짧은 길에는 빠른 무기, 긴 길에는 사거리 긴 무기가 좋다.
  - 무기를 다른 면으로 옮기는 건 공짜지만 **옮긴 무기는 3초 동안 쏘지 않는다**. 예보를 보고 미리 옮겨 두자.
  - **탑 돌리기**: 탑 전체를 90° 돌려 모든 무기를 한 칸씩 옮긴다. 쉬지 않고 바로 쏘지만, 한 번 돌리면 8초 기다려야 한다.
    가장 센 면을 적이 몰린 쪽으로 휙 돌리는 게 이 게임의 손맛. (천천히 정리할 땐 옮기기, 급할 땐 돌리기)
- **길과 예보**: 땅 적은 네 길 끝에서 나와 길을 따라 온다 (박쥐는 그 길 쪽 가장자리 여기저기서 비스듬히 날아온다).
  - 1~3라운드: 한 길로만 (같은 길)
  - 4~9라운드: 두 길로 60% · 40%. 새 길은 40% 로 먼저 오고, 다음 라운드에 60% 가 된다
  - 10라운드부터: 네 길 모두, 한 길이 40% (그 길은 라운드마다 바뀐다)
  - 지금 오는 길은 길 끝에 작게, 라운드가 끝나기 **6초 전**부터 다음 라운드 방향이 `다음 60%` 처럼 크게 뜬다.
    정예·보스는 그 라운드에 가장 많이 오는 길로 오고, 예보에 `정예`·`보스` 가 함께 뜬다.
- **난이도**: 쉬움(체력 1500 · 시작 골드 450 · 적 체력 ×1.13/라운드) / 보통(×1.17) / 어려움(×1.22, 적이 더 많음)
- **정예**: 5·10라운드 시작 때, 그때 나올 수 있는 가장 튼튼한 적이 체력 ×3.5 · 공격력 ×1.5 · 현상금 ×8 로 나온다. 잡으면 보상 카드가 한 번 더 나온다.
- **무기 5계열 × 3종**

  | 계열 | 방식 | 무기 |
  | --- | --- | --- |
  | 일반 | 단일 대상 | 돌팔매, 쌍단검, 전투 도끼 |
  | 관통 | 가장 가까운 적 방향 직선 위를 모두 꿰뚫음 | 장궁, 질풍 활, 노포 |
  | 마법 | 연쇄 번개 / 둔화 | 연쇄 번개, 폭풍 수정, 서리 구슬 |
  | 공성 | 착탄 지점 주변 광역 | 박격포, 투석기, 화염 항아리 |
  | 카오스 | 피해가 매번 50~200% | 혼돈 구슬, 혼돈의 눈, 공허 광선 |

- **면 세트**: 한 면에 같은 계열 무기 2개 → 그 면의 그 계열 피해 +20%, 3개(면 가득) → +50% 와 특수 효과. ★ 와 상관없이 하나는 하나로 센다.
  - 일반: 공격 속도 +25% · 관통: 사거리 +40 · 마법: 연쇄 +2회, 둔화 +1초 · 공성: 폭발 반경 ×1.3 · 카오스: 피해 하한 100%
  - 한 면을 한 계열로 몰아 세게 만들지, 네 면을 고르게 채울지 고민하게 된다.
- **강화 9종**: 튼튼한 벽(최대 체력), 재생의 룬, 강철판(방어), 전투 교본(피해 +10%), 황금 동전(초당 골드), 신속의 룬(공격 속도 +25%, 최대 ×3), 예리한 칼날(치명타 10%, 2배), 가시 갑옷(탑을 때린 적에게 15), 망원경(사거리 +15)
- 방어력: 받는 피해 = 공격력 / (1 + 방어력 × 0.05)
- **무기 합성**: 같은 무기 ★1 3개 → ★2 (피해 ×3.5, 공격 속도 ×1.1), ★2 3개 → ★3 (피해 ×12, 공격 속도 ×1.25).
  합쳐진 무기는 재료가 가장 많이 있던 면에 남는다. 고른 면이 꽉 차면 사자마자 합쳐지는 무기만 살 수 있다.
- **판매**: 탑 옆 무기 칸을 눌러 집고 옆에 뜨는 `팔기` 를 누른다. 산 값(★2 는 3배, ★3 은 9배)의 50% 환급.
- **보상 카드** (특전과 스킬을 한 번에): 3라운드마다, 그리고 정예를 잡을 때마다 게임이 멈추고 3장 중 1장을 고른다.
  스킬로 할 것이 있으면 스킬 카드가 1~2장 섞인다. 할 것이 하나도 없으면 골드 주머니.
  - 특전 12종 (한 판에 한 번씩, 상점 강화와 겹치지 않는 것만): 이자 · 흡혈 탑 · 시체 폭발 · 다중 사격 · 전도체 · 거인 사냥꾼 · 현상금 사냥꾼 · 할인 · 무료 리롤 · 주문 숙련 · 냉기 오라 · 대폭발
  - 스킬 카드: **새 스킬**(빈 칸에 배움) · **진화**(가진 기본 스킬이 세짐) · **합체**(가진 두 스킬을 하나로)
- **스킬**: 메테오 하나로 시작한다. 칸은 4개(`Q` `W` `E` `D`).
  - 기본 스킬 7종. **길 스킬**은 마우스가 있는 길(없으면 적이 가장 많은 길) 하나에 듣는다.

    | 스킬 | 속성 | 재사용 | 효과 | 진화 |
    | --- | --- | --- | --- | --- |
    | 메테오 | 불 | 30초 | 지점 반경 55 에 큰 피해 | 유성우: 다른 두 무리에도 운석 |
    | 눈보라 | 얼음 | 40초 | 길 스킬: 그 길의 적 4초 얼림 | 영구 동토: 6초 |
    | 긴급 수리 | 치유 | 50초 | 체력 35% 회복 | 생명의 샘: 60% |
    | 골드 러시 | 금 | 60초 | 10초 현상금 2배 | 황금 시대: 15초 3배 |
    | 천둥 | 번개 | 35초 | 가장 튼튼한 5마리에게 벼락 | 뇌신: 10마리 |
    | 돌풍 | 바람 | 35초 | 길 스킬: 그 길의 적을 110 밀어내고 약한 피해 | 태풍: 170 |
    | 바리케이드 | 땅 | 35초 | 길 스킬: 탑에서 90 떨어진 곳을 6초 막음 (박쥐는 못 막음) | 철벽: 10초, 막힌 적은 계속 다침 |

  - **합체**: 가진 두 스킬을 하나로. 칸이 하나 빈다. 진화한 재료 하나당 +30%.
    합체에 쓴 기본 스킬은 다시 배울 수 없다. 합체 스킬은 모든 적에게 듣는다.

    | 합체 | 재료 | 효과 |
    | --- | --- | --- |
    | 혜성 | 메테오 + 눈보라 | 반경 70 에 1.5배 피해, 맞은 적 4초 얼음 |
    | 황금 운석 | 메테오 + 골드 러시 | 1.5배 운석 + 골드 러시 |
    | 천벌 | 메테오 + 천둥 | 가장 튼튼한 8마리에게 2배 벼락 |
    | 얼음 성벽 | 눈보라 + 긴급 수리 | 모두 얼리고 35% 회복, 6초 동안 받는 피해 -70% |
    | 설풍 | 눈보라 + 돌풍 | 80 밀어내고 4초 얼림 |
    | 연금술 | 긴급 수리 + 골드 러시 | 35% 회복 + 골드 (100 + 라운드×30) |
    | 폭풍 | 천둥 + 돌풍 | 90 밀어내고 6마리에게 벼락 |

  - 스킬 피해는 라운드에 따라 적 체력만큼 같이 강해진다.
- **적**

  | 적 | 등장 | 특징 |
  | --- | --- | --- |
  | 고블린 · 늑대 · 오크 · 돌 골렘 | 1 · 3 · 4 · 7R | 기본 적 |
  | 분열 슬라임 | 3R | 죽으면 새끼 슬라임 둘로 나뉨 |
  | 도둑 고블린 | 4R | 탑을 때리지 않고 골드를 훔쳐 달아남. 놓치면 골드를 잃고, 잡으면 되찾음 |
  | 방패병 | 5R | 일반·관통 무기 피해 절반 |
  | 주술사 | 6R | 멀찍이 멈춰 서서 2초마다 주변 적 치유 |
  | 박쥐 | 8R | 날아다녀서 공성(광역) 무기에 맞지 않음, 길 쪽 가장자리 여기저기서 비스듬히 옴 |

  정예는 특수 능력이 없는 적 중에서만 나온다.
- **보스 3종**: 클래식 15라운드(무한은 15라운드마다)에 셋 중 하나가 나온다. 무한 모드에서는 바로 전 보스는 다시 나오지 않는다.

  | 보스 | 체력 | 패턴 (주기) |
  | --- | --- | --- |
  | 땅굴 군주 | 105,000 | 소환 (5초): 주변에 늑대·오크 6마리 |
  | 강철 뿔 | 90,000 | 돌진 (5초): 빠르게 달려와 공격력 ×3 으로 들이받음. 들이받힌 면의 무기는 2초 기절 |
  | 불꽃 마녀 | 80,000 | 화염 폭풍 (6초): 공격력 ×8 |

  - 보스는 마지막 라운드에 가장 많이 오는 길로 와서, 탑에서 115 떨어진 곳에서 **탑 둘레를 돌며** 멀리서 쏜다 (0.3 라디안/초, 약 21초에 한 바퀴).
    패턴을 쓸 때마다 도는 방향이 바뀐다. 보스를 따라 탑을 돌려야 한다. 강철 뿔은 들이받은 뒤 다시 궤도로 물러난다.
  - 패턴 전에 기를 모은다 (1~2초, 머리 위 `!` 와 경로·범위 표시). 이때 그 길에 눈보라를 쓰거나 최대 체력의 4% 이상을 때리면 끊긴다.
  - 얼어 있는 동안에는 다음 패턴까지의 시간도 멈춘다.
  - 체력이 절반 아래로 내려가면 날뛴다: 이동 속도 ×1.3, 패턴 주기 ×0.6.
- **탑 5종** (시작 화면에서 고름)

  | 탑 | 시작 무기 | 고유 능력 | 해금 |
  | --- | --- | --- | --- |
  | 수호탑 | 돌팔매 | 최대 체력 +200, 라운드마다 체력 10% 회복, 무기가 없는 면으로 받는 피해 -40% | 처음부터 |
  | 궁수탑 | 장궁 | 관통 피해 +30%, 관통 사거리 +30 (긴 동·서 길에 강함) | 별조각 30 |
  | 마법탑 | 연쇄 번개 | 마법 무기는 150° 를 쏜다, 마법 피해 +20%, 연쇄 +1, 스킬 대기 -25% | 40 |
  | 요새 | 박격포 | 체력 +300, 방어 +6, 가시 20, 공성 +20%, 면마다 무기 칸 2 | 50 |
  | 도박탑 | 혼돈 구슬 | 치명타 +10%, 카오스 피해 최대 300%, 리롤 반값 | 60 |

- **별조각** (판이 끝나면): 라운드 × 2 + 처치 수 / 40 + (클래식 승리 25 | 무한 보스 1마리당 15), 쉬움 ×0.7 · 어려움 ×1.5
- **영구 강화**: 시작 골드 +40 · 최대 체력 +80 · 피해 +4% (각 5단계), 탑 4종 해금 (예전에 없앤 강화에 쓴 별조각은 불러올 때 돌려준다),
  전설 무기 3종 해금 (천둥 망치 · 불사조 활 · 유성 지팡이 — 해금하면 상점에 섞여 나온다)
- **업적 14개**: 첫 승리, 계열 하나로만 승리 (5계열 각각), 스킬 없이 승리, 어려움 승리, 체력 80% 이상 남기고 승리,
  ★3 무기, 무한 30라운드, 무한 한 판에 보스 3마리, 골드 2000 들고 끝내기, 다섯 탑 모두로 승리. 처음 달성할 때 별조각을 준다.
- **연습 판**: 처음 시작하면 진짜 판 전에 연습 판이 열린다 (위쪽 `건너뛰기` 로 언제든 넘길 수 있다).
  한 단계씩 게임이 멈추고, 눌러야 할 곳이 금색으로 반짝이며, 직접 해야 넘어간다:
  무기 사기 → 부채꼴 쪽만 쏘는 것 보기 → 반대쪽 면 고르고 사기 → 탑 돌리기 → 다음 라운드 예보 → 메테오. 설명 단계는 `다음`(Enter · Space).
  연습 판이 끝나면 첫 판은 **쉬움**으로 시작하고, 시작 화면도 첫 판에는 쉬움을 골라 둔다.
- **빈 면 알림**: 무기가 없는 면으로 맞으면 그 면 칸이 빨갛게 번쩍이고 `북쪽이 비었다!` 가 뜬다 (같은 면은 4초에 한 번).
- **첫 판 안내**: 처음 하는 판에는 왼쪽 아래에 그때그때 필요한 안내가 하나씩 뜬다 (무기 사기 → 빈 면 쪽으로 적이 올 때·예보가 뜰 때 면 고르기 → 두 길이 시작되거나 보스가 나오면 탑 돌리기 → 합성 직전 → Q, 보스가 기를 모으면 끊는 법).
- 최고 기록 · 별조각 · 강화 · 업적 · 마지막으로 고른 탑은 브라우저(localStorage)에 저장된다. 클래식은 난이도별 최고 라운드 · 승리 수 · 최단 승리 시간, 무한 모드는 난이도별 최고 라운드 · 최다 처치.

## 이야기

탑 다섯 개에는 저마다 사연을 가진 수호자가 깃들어 있고, 탑마다 이야기가 따로 있다.

| 탑 | 수호자 | 이야기 |
| --- | --- | --- |
| 수호탑 | 바우 | 성문을 닫지 못한 은빛성의 늙은 문지기 |
| 궁수탑 | 솔 | 괴물 발자국을 쫓아 별무덤을 찾는 푸른숲 사냥꾼 |
| 마법탑 | 루미 | 스승과 함께 별을 끌어내린 별지기탑 견습생 |
| 요새 | 무쇠 | 왕의 명으로 별을 쪼갠 공성 기술자 |
| 도박탑 | 딸랑 | 마을을 판돈으로 안개와 내기를 한 떠돌이 도박사 |

- 서장·결말 카드와 이야기 책에는 수호자 도트 초상화가 나온다 (서막·마지막 이야기는 길잡이별).
- **서장**: 클래식에서 그 탑을 처음 고르면 판 시작 전에 뜬다 (맨 처음에는 서막부터). 클릭·Enter 로 넘기고 Esc 로 건너뛴다.
- **판 도중**: 1·3·5·7·10·12라운드에 이야기가 한 줄씩 이어지고, 장수(보스) 등장·체력 30% 아래에서도 수호자가 탑 위 말풍선으로 한마디. 보스 대사는 탑과 보스 조합마다 다르다.
- **결말**: 그 탑으로 클래식을 처음 이기면 결말이 뜨고, 잿빛 왕에 관한 **진실 조각**을 하나씩 밝힌다.
- **마지막 이야기**: 다섯 탑 모두로 이기면 열린다.
- 시작 화면 `이야기 (T)` 에서 연 쪽을 다시 읽을 수 있다. 안 읽은 쪽은 N 표시.

내용은 모두 `src/core/story.ts` 에 있다.

## 소리

소리 파일 없이 Web Audio 로 그 자리에서 합성한다.

- 방향: 서쪽에서 맞으면 왼쪽, 동쪽이면 오른쪽 스피커에서 들린다. 착탄·스킬도 화면 x 위치에 따라 좌우로 나뉜다.
- 착탄음은 투사체가 실제로 떨어지는 순간에 맞춰 울린다 (쏘는 소리와 따로).
- 음 + 잡음(필터) 을 겹쳐 두께를 내고, 마지막에 압축기를 걸어 한꺼번에 터져도 찢어지지 않게 한다.
- 알림 소리: 빈 면 피격 경고, 다음 라운드 예보 종, 연습 판 단계 넘김, 체력 30% 아래 심장 박동(낮을수록 빨라짐), 바리케이드
- 배경음악(칩튠, 코드로 연주): 시작 화면·연습(느긋한 5음계) · 낮(가 단조) · 밤(라 단조, 더 빠름) · 보스(미 화성 단조, 가장 빠름).
  적이 많아질수록 북·가락이 겹겹이 더해지고, 곡은 마디가 끝날 때 바뀐다.
- 효과음·음악 음량과 모두 끄기는 ♪ 창에서 따로 정하고 저장된다.

## 화면

- 16:9 전장 하나 위에 모든 UI 가 떠 있다. 적·탑·전장은 도트 그림, UI 는 둥근 반투명 창과 아이콘.
  - 위: 라운드 · 남은 적 · 골드 · 체력 알약, 오른쪽 위 작은 버튼(정보 · 배속 · 정지 · 소리)
  - 가운데: 탑과 둘레의 네 면 무기 칸 (면 이름, 고른 면은 금색)
  - 네 길 끝: 지금 오는 길의 비율, 라운드 끝 무렵에는 다음 라운드 예보
  - 아래: 스킬 버튼과 양옆 탑 돌리기 버튼, 그 아래 상점 카드 한 줄과 ⟳ 새로 고침

- 글꼴은 [Pretendard](https://github.com/orioncactus/pretendard) (SIL OFL) 를 CDN 에서 불러오고, 못 불러오면 시스템 한글 글꼴로 그린다.

모든 수치는 `src/core/config.ts`(규칙·난이도·면·길·세트·보상 카드), `src/core/data.ts`(무기·강화·적·보스 패턴), `src/core/heroes.ts`(탑), `src/core/meta.ts`(영구 강화)에서 조정한다.
