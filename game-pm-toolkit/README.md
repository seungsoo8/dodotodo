# 게임 사업PM 툴킷

게임 회사 사업PM 업무에서 자주 반복되는 세 가지 작업을 자동화/체계화하는 로컬 대시보드입니다.

- **지표 리포트 자동화** (`/metrics`): 매출·DAU·리텐션 등 지표를 직접 입력하거나 CSV로 붙여넣으면, 주간/월간 기준 전기 대비 증감을 자동 계산하고 보고서에 바로 붙여넣을 요약 텍스트를 생성합니다.
- **경쟁작/마켓 트래커** (`/competitors`): 경쟁작을 등록하고 업데이트·이벤트·프로모션·순위 변동을 타임라인으로 기록해 흩어져 있던 시장 동향을 한곳에서 확인합니다.
- **피드백/버그 트리아지 보드** (`/feedback`): 스토어 리뷰, CS, 디스코드 등 여러 채널에서 들어온 피드백을 하나의 칸반 보드(수집→검토→우선순위 지정→진행중→완료)로 모아 영향도·우선순위 점수로 관리합니다.

## 실행 방법

```bash
npm install
npm run dev
```

`http://localhost:3000` 에서 확인할 수 있습니다.

## 데이터 저장

별도 인프라 없이 SQLite 파일(`data/app.db`)에 로컬로 저장됩니다. 첫 실행 시 자동으로 테이블이 생성됩니다. `data/` 폴더는 `.gitignore`에 포함되어 있어 커밋되지 않습니다.

## 향후 확장 아이디어

- 지표: 스토어 콘솔/BI 툴 API 연동으로 수동 입력 대체
- 피드백: CS 티켓/디스코드 웹훅으로 자동 수집
- 경쟁작: 스토어 순위 자동 스냅샷
